# Ruihong Cen Personal Website

Astro-based academic personal website for GitHub Pages.

## Commands

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Content

- Publications: `src/content/publications/publications.json`
- Projects: `src/content/projects/*.md`
- Hidden writing: `src/content/writing/*.mdx`

The public navigation is limited to Home, Publications, Projects, and About.
The writing section is available at `/writing/`, but it is intentionally unlisted
and marked `noindex, nofollow`.
